# Image credits

Rule: only images that are free for commercial use with no licence fee (Unsplash, Pexels, Pixabay: check each image's licence; public domain; or images supplied by the client). Never copy images from competitors, Google Images, Pinterest, social media or other travel companies. Never hotlink: download, optimise to WebP and store in the project. Avoid recognisable logos, trademarks and private property that needs a release.

## How to replace
- Tour type / destination images: Admin > Tour types or Destinations > upload (alt text required).
- Package galleries: Admin > Packages > Gallery.
- Hero / default share image: replace the file in `public/images/` with the same name (keep the dimensions), or upload a share image in Admin > Settings.
- Then add a row to a "Real images" table below for each image: filename, source URL, photographer, licence, where used, and any credit the licence requires (add the credit to the page footer if required).
